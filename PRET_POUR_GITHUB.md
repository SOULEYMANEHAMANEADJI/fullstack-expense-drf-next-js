Si vous utilisez le script pour la première fois et que vous avez déjà un repository sur GitHub, le script utilisera `--force` pour pousser. C'est normal pour un premier déploiement.

Si vous souhaitez faire un push manuel sans `--force` :

```bash

git add .
git commit -m "🎉 Initial commit - Application complète"
git branch -M main
git push -u origin main
```
